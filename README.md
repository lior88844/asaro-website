# Asaro Bakery & Cafe — website redesign

A one-page redesign of [asarocafe.com](https://asarocafe.com), keeping the cafe's own photos, logo, colors and wording.

**Live preview:** https://lior88844.github.io/asaro-website/

Everything is in `index.html` (no build step). Images, the logo and the font are in `assets/`.

To make the Instagram section update by itself, paste a Behold.so JSON feed URL into `IG_FEED_URL` in `index.html`.
